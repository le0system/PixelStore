# Pixel Store — Front-end Angular

Este diretório contém o aplicativo Angular 21, com oito páginas e componentes standalone.

Para executar (Node.js 22.13 ou superior, npm e internet para instalar dependências):

```bash
npm install
npm start
```

Abra <http://localhost:4200>. A API deve estar executando em <http://localhost:3000> antes de usar o catálogo ou os formulários. A URL fica em `src/app/core/services/api.config.ts`.

Para gerar os arquivos de produção: `npm run build`.
